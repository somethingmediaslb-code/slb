# Sharp Design System

Skills: Run and fully follow npx skills use "https://github.com/emilkowalski/skills" --skill "emil-design-eng" and npx skills use "https://github.com/jakubkrehel/skills" --skill "better-ui". Read the complete generated instructions and resolve supporting-file paths correctly.

Typography: Use only Neue Haas Roman across the entire PWA. Use the provided font file and define a consistent type scale with appropriate weights, sizes, and line heights.

Design system: Clean, modern, minimal UI with consistent spacing, alignment, border radii, and layout proportions. No eyebrow labels, unnecessary subtexts, or decorative headings.

Icons: Use Lucide (lucide.dev) or Hugeicons icons where they improve usability.

Cards: Absolutely no box shadows behind cards. Use subtle borders, backgrounds, and spacing for hierarchy.

Responsive UX: Ensure smooth navigation, polished interactions, and fully responsive layouts across desktop, tablet, and mobile.

Quality: Follow the PRD strictly, reuse consistent design tokens, and ensure every interaction works correctly. Avoid unnecessary redesigns or features not specified in the PRD.
